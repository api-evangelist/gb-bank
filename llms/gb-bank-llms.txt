# GB Bank

> GB Bank Limited is a UK challenger bank (FCA/PRA-authorised, Financial Services Register 850286; Companies House 10702260) headquartered in Middlesbrough with a London office. It funds SME regional property development, buy-to-let and bridging loans with retail savings (fixed-rate bonds, notice and easy-access accounts, FSCS-protected to £85,000). GB Bank is not a CMA9 bank and operates no confirmed public developer portal; the UK Open Banking (OBIE) API families below are represented as the shared industry standard an FCA-authorised ASPSP conforms to and are UNVERIFIED for GB Bank (no live GB Bank API host or base URL was found or invented).

## APIs (represented as the shared OBIE standard - unverified for GB Bank)
- [GB Bank Open Data API (OBIE v1.3)](https://github.com/OpenBankingUK/opendata-api-spec-compiled): Unauthenticated reference data - ATMs, Branches, PCA, BCA, SME loans, commercial credit cards.
- [Account & Transaction Information API (AIS)](https://github.com/OpenBankingUK/read-write-api-specs): FAPI-secured account, balance, transaction and statement access with PSU consent.
- [Payment Initiation API (PIS)](https://github.com/OpenBankingUK/read-write-api-specs): FAPI-secured domestic/international/file payment initiation with PSU consent.
- [Confirmation of Funds API (CBPII)](https://github.com/OpenBankingUK/read-write-api-specs): FAPI-secured funds-availability confirmation with PSU consent.
